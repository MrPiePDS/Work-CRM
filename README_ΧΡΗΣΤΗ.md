# README_ΧΡΗΣΤΗ.md
# 🧾 CRM Εφαρμογή Πελατών (Client Manager) — Οδηγός Χρήσης

## 1) Τι είναι CRM;
CRM σημαίνει **Customer Relationship Management**.  
Με απλά λόγια: είναι ένα “τετράδιο” ή “βιβλίο” όπου **γράφουμε και οργανώνουμε τους πελάτες**.

### Γιατί το χρειαζόμαστε;
Για να:
- μην ψάχνουμε χαρτιά και σημειώσεις
- μην μπερδεύουμε πελάτες
- βρίσκουμε γρήγορα στοιχεία
- κρατάμε **ιστορικό** (ποιος έκανε τι και πότε)
- έχουμε **αρχεία** (έγγραφα) σε σωστό φάκελο

---

## 2) Τι είναι αυτή η εφαρμογή;
Αυτή είναι μια μικρή εφαρμογή για Windows που:
- δουλεύει **μόνη της** (χωρίς internet)
- κρατά τους πελάτες σε ένα αρχείο Excel (το κάνει αυτόματα)
- φτιάχνει φακέλους για τα έγγραφα κάθε πελάτη
- γράφει “ποιος έκανε τι” για να μην υπάρχουν παρεξηγήσεις

---

## 3) Πώς την ανοίγω;
1. Κάνε διπλό κλικ στο αρχείο **app.exe**
2. Θα δεις τη σελίδα **Login**

> Σημείωση: Την πρώτη φορά υπάρχει default χρήστης (admin). Μετά αλλάζουμε κωδικό.

---

## 4) Login (Είσοδος)
- Γράφεις:
  - Username
  - Password
- Πατάς **Login**

Αν κάνεις λάθος:
- θα σου πει “Wrong credentials”
- ξαναδοκίμασε

---

## 5) Μενού της εφαρμογής
Η εφαρμογή έχει 3 βασικές καρτέλες:

1) **New customer** (Νέος πελάτης)  
2) **Search** (Αναζήτηση)  
3) **Dashboard** (Λίστα όλων)

---

# ✅ 6) New customer (Νέος πελάτης) — Βήμα-βήμα

## Βήμα 1: Διάλεξε τύπο υπηρεσίας
Πάνω πάνω έχει:
- **KEP**
- **Nomika**

Διάλεξε ένα.

## Βήμα 2: Γράψε τα στοιχεία
Συμπλήρωσε:
- Date (μπαίνει μόνο του)
- Name & Surname
- Phone number
- Taxisnet (μόνο σημείωση, όχι κωδικοί)
- Kleidarithmos (Confirmed / Rejected)
- AMKA/AMA (Confirmed / Rejected)
- Aporipsi (Yes / No)
- Customer request / notes (τι ζητάει ο πελάτης)

## Βήμα 3: Επιβεβαίωση (δύο κουτάκια)
Πρέπει να τσεκάρεις:
- ✅ I confirmed the customer data
- ✅ I confirmed the selected services & pricing

> Αν δεν τα τσεκάρεις, δεν σε αφήνει να κάνεις αποθήκευση.

## Βήμα 4: Διάλεξε τι κάναμε σήμερα (ΥΠΟΧΡΕΩΤΙΚΟ)
Υπάρχουν κουτάκια όπως:
- AMKA / AMA (160)
- Metavoli / Change (20)
- Key number (20)
- AFM / Tax number (50)
- Work (75)

✅ Πρέπει να επιλέξεις **τουλάχιστον 1**.

## Βήμα 5: Πληρωμή
- Γράψε στο “Paid today” πόσα έδωσε
- Η εφαρμογή δείχνει:
  - Total (σύνολο)
  - Balance (υπόλοιπο)

## Βήμα 6: Αποθήκευση πελάτη
Πάτα:
- **Save customer to Excel**

Τι κάνει αυτό;
- Αποθηκεύει τον πελάτη στο Excel
- Δίνει νέο ID
- Φτιάχνει φάκελο για τα αρχεία του πελάτη

Θα δεις μήνυμα:
- “Customer saved with ID …”

---

# 📂 7) Files (Αρχεία) — Πώς βάζω έγγραφα

⚠️ Πρώτα σώσε πελάτη (Save), μετά βάλε αρχεία.

Έχεις 3 λίστες:
- **Pending files**: αρχεία που διάλεξες αλλά δεν τα μετέφερες ακόμα
- **Customer folder files**: αρχεία που υπάρχουν στον φάκελο του πελάτη
- **Scanner folder files**: αρχεία από τον φάκελο του scanner (αν έχει οριστεί)

## Βάζω αρχεία με 2 τρόπους:
### Α) Drag & Drop
- Ρίξε αρχεία στο πλαίσιο “Drag & Drop files here”
- Θα μπουν στο “Pending files”

### Β) Add files…
- Πατάς **Add files…**
- Διαλέγεις αρχεία

## Μεταφορά στον πελάτη
- Πατάς **Move pending → customer folder**
και τα αρχεία μπαίνουν στον φάκελο του πελάτη.

## Από scanner folder
1. Γράφεις ή διαλέγεις Scanner folder
2. Πατάς “Refresh lists”
3. Διαλέγεις αρχείο από “Scanner folder files”
4. Πατάς **Move selected scanner → customer folder**

## Print
- Διαλέγεις αρχείο από “Customer folder files”
- Πατάς **Print selected (customer folder)**

## Confirm files
- Πατάς **Confirm files**
Αυτό γράφει ότι “τα αρχεία επιβεβαιώθηκαν” (ποιος και πότε).

---

# 🔎 8) Search (Αναζήτηση)
Μπορείς να ψάξεις με:
- ID
- Name
- Phone

✅ Πρέπει να βάλεις **τουλάχιστον ένα**.

Μετά:
- Πατάς **Search**
- Βλέπεις λίστα αποτελεσμάτων
- Κάνεις διπλό κλικ σε πελάτη για να ανοίξει.

---

# 👤 9) Customer details (Σελίδα πελάτη)
Εκεί βλέπεις:
- στοιχεία πελάτη
- Notes
- λίστα αρχείων του πελάτη
- History (audit log): ποιος έκανε τι και πότε

Μπορείς:
- να αλλάξεις Notes
- να πατήσεις **Save changes**
- να πατήσεις **Open folder**
- να πατήσεις **Print selected**

---

# 📊 10) Dashboard (Λίστα όλων)
Δείχνει όλους τους πελάτες και:
- αν υπάρχουν αρχεία (Yes/No)
- πόσο καιρό είναι “ανοιχτός” (Serving time)

---

# 🧠 11) Πού αποθηκεύονται τα δεδομένα;
Η εφαρμογή τα κρατά μόνη της στον υπολογιστή, εδώ:
`AppData\Roaming\ClientManagerV1\`

Εκεί έχει:
- `clients.xlsx` (οι πελάτες)
- `audit_log.csv` (ιστορικό ενεργειών)
- `users.json` (χρήστες)
- `clients\` (φάκελοι πελατών)

✅ Εσύ δεν χρειάζεται να το πειράξεις.

---

# ✅ 12) Τι να θυμάσαι (το πιο σημαντικό)
- Πάντα πρώτα **Save customer**
- Μετά βάλε **files**
- Πάντα κάνε **Confirm files** όταν τελειώσεις
- Για να βρεις πελάτη: πήγαινε **Search**
- Για γενική εικόνα: πήγαινε **Dashboard**
